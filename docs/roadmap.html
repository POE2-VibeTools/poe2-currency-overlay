Roadmap

What's planned next. Release targets are aims, not promises.

Targeting ~2.4

Currency-tab CalculatorIn progress

Reads your special currency tabs and tells you the exact value of everything in them. Flip through them all and it totals what your stash is worth. Every currency tab type except the Map tab.

Regex Builder / Tab FilterPlanned

Build and save regex searches to help find and sort items inside your stash.

Command HotkeysPlanned

Bind a hotkey to a safe, non-disruptive in-game chat command like /hideout. One key, one manually-triggered command - nothing GGG's rules disallow.

Reorder currencies within a bucketPlanned

Drag the currencies inside a bucket to reorder them, so each bucket sits the way you like instead of the default order.

Multi-select when adding to a bucketPlanned

Add several currencies to a bucket at once with multi-select, instead of one at a time.

Targeting ~2.5

Dedicated Arbitrage Route tabPlanned

A tab where you can build and check your own trade routes, instead of only viewing the single best route the app finds for a pair.

In-app bug reportingPlanned

Report a specific thing that misbehaved - a currency row, a search, a result, a desecration - straight from the app, with the real underlying data attached.

Targeting ~2.6

Full currency exchange tableIdea

A one-glance view of every currency you hold with its live exchange rate to Exalted, auto-populated. Inspired by Ange's in-game market screen. Community-suggested.
